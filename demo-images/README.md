# Demo image configurations

These files are tracked examples generated by `lucas_squares.py`.

## `lucas-turning.svg`

- Format: SVG
- Iterations: `8` (`exact` mode)
- Layout: `turning`
- Alignment: `seamless`
- Labels: enabled
- Page: `12 × 9` inches
- Margin: `0.45` inches
- SVG coordinate density: `100` units per inch

Generated with `python lucas_squares.py --iterations 8 --labels --format svg --output demo-images/lucas-turning.svg`.

## `lucas-turning.png`

- Format: PNG
- Iterations: `8` (`exact` mode)
- Layout: `turning`
- Alignment: `seamless`
- Labels: enabled
- Page: `12 × 9` inches
- Margin: `0.45` inches
- Resolution: `150` DPI

Generated with `python lucas_squares.py --iterations 8 --labels --format png --dpi 150 --output demo-images/lucas-turning.png`.

## `lucas-letter-fit.pdf`

- Format: vector PDF with selectable labels
- Iterations: up to `12` (`auto` mode)
- Layout: `fit`
- Alignment: `seamless`
- Labels: enabled
- Page: US Letter portrait, `8.5 × 11` inches
- Margin: `0.25` inches

Generated with `python lucas_squares.py --iterations 12 --count-mode auto --layout fit --width 8.5 --height 11 --margin 0.25 --labels --format pdf --output demo-images/lucas-letter-fit.pdf`.
